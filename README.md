# Signin Page

A clean, responsive sign-in page built with pure HTML, CSS, and JavaScript.

## Preview

Split-panel layout — white form on the left, green welcome panel on the right.

## Features

- Username & password input fields
- Signin button with hover animation
- Social login icons (Facebook, Google, LinkedIn)
- "No account yet? Signup." link
- Enter key support for form submission
- Responsive design (stacks vertically on mobile)

## Files

| File | Description |
|------|-------------|
| `signin.html` | Single-file app — all HTML, CSS & JS included |

## Usage

Just open `signin.html` in any browser — no server or dependencies needed.

## Tech Stack

- **HTML5** — semantic structure
- **CSS3** — flexbox layout, transitions, animations
- **Vanilla JS** — form validation, keyboard support
- **Google Fonts** — Poppins typeface

## Customization

| What | Where |
|------|-------|
| Brand color | `#3dba7e` (search & replace) |
| Welcome text | Right panel `<p>` tag |
| Form action | `handleSignin()` function in `<script>` |
